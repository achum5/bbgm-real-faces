# BBGM Real Faces

Hand-picked faces for every real player in [Basketball GM](https://play.basketball-gm.com/), 1946 to 2030.

Site: https://achum5.github.io/bbgm-real-faces/

- `players.json`: `[srID, name, draft year, photo URL, face, score, [jersey, team colors]]` for each player
- `real-faces-2027-preseason.json.gz`: league file with every face, 2027 preseason
- `jerseys.json`: each real team's jersey style by era, used with the real team names option
- `faces.js`: [facesjs](https://github.com/zengm-games/facesjs) 5.0.3, bundled
